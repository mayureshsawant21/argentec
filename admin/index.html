Admin panel

The admin panel is ready, but it isn't connected to the database yet.

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste the contents of supabase/setup.sql and run it.
  3. Under Authentication → Users, add the admin user (email and password), then run the last line of setup.sql with that email.
  4. Copy the Project URL and anon public key from Project Settings → API into js/backend-config.js.

Full steps are in the README under “Admin panel”.
